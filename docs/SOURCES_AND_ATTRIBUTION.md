# 자료 출처 및 권리 안내

이 문서는 제주너머 데모가 사용하는 지도, 문화 근거, 제주어 용례와 시각 에셋의 출처를 구분해 기록합니다. 저장소 전체에 적용되는 오픈소스 라이선스는 아직 지정하지 않았습니다.

## 1. 지도 경계

- 가공 데이터: [vuski/admdongkor](https://github.com/vuski/admdongkor)
- 기준 버전: 2026-07-01 행정동 경계
- 원자료: 통계청 SGIS 행정구역 경계
- 가공 데이터 표시 라이선스: CC BY 4.0
- 원자료 표시 조건: 공공누리 제1유형 출처표시

실행용 축약 데이터는 `web/jeju-map-data.js`입니다. 원본 GeoJSON은 약 33MB의 크기와 재배포 조건 관리를 위해 저장소에서 제외했습니다. 별도로 받은 원본을 다음 명령에 전달하면 14개 탐험 권역 데이터를 다시 만들 수 있습니다.

```powershell
uv run python scripts/build_jeju_eup_map.py `
  --source C:\path\to\HangJeongDong_ver20260701.geojson
```

## 2. 문화 자료

문화 판정과 시나리오 검수에 사용한 승인 자료는 `app/data/evidence.json`에 제목, 발행기관, URL, 접근일과 라이선스를 함께 기록합니다. 주요 기관은 다음과 같습니다.

- 제주특별자치도 제주어 교육 플랫폼 페우다
- 제주학연구센터
- 국가유산청 국가유산포털
- 제주관광공사 비짓제주
- 국립민속박물관 한국민속대백과사전
- 한국학중앙연구원 한국민족문화대백과사전

게임과 에이전트는 원문 전체를 복제하지 않고, 판정에 필요한 짧은 사실 요약과 용례·출처 식별자만 승인 레지스트리에 보관합니다. 자료를 추가할 때는 해당 기관의 이용 조건을 다시 확인해야 합니다.

## 3. 제주어 용례

제주어 판정에 사용한 형태와 사용 맥락은 제주특별자치도 제주어 교육 플랫폼과 제주학연구센터의 공개 자료를 중심으로 구성했습니다. 각 형태의 허용 범위, 표준어 의미, 사용 맥락, 예시는 `app/data/evidence.json`에서 개별 근거 ID로 관리합니다.

모델의 일반 지식만으로 새로운 제주어 정답을 만들지 않습니다. 검색 결과가 반환되어도 로컬 승인 레지스트리의 ID·버전·퀘스트 범위를 다시 확인합니다.

## 4. 시각 에셋

`web/assets/`의 바람새, NPC, 배경, 지도 질감 이미지는 제주너머 데모를 위해 제작·생성·편집한 프로젝트 에셋입니다. 외부 공개 저장소에서 내려받은 사진을 그대로 포함하지 않습니다.

이 이미지들은 코드와 별개의 창작 에셋이므로 재사용·재배포 조건을 정하려면 팀원 합의가 필요합니다. 코드에 오픈소스 라이선스를 추가하더라도 이미지 에셋이 자동으로 같은 라이선스가 되는 것은 아닙니다.

## 5. 코드 이용 조건

현재 저장소에는 별도 `LICENSE`가 없습니다. 따라서 포트폴리오 열람은 가능하지만 제3자에게 복제·수정·배포 권한을 명시적으로 부여하지 않습니다. 오픈소스로 공개하려면 팀원과 다음 사항을 먼저 결정해야 합니다.

- 코드 라이선스 종류
- AI 생성·편집 이미지의 재사용 범위
- 지도·문화 자료의 예외 및 출처 표시 방식
- 팀원 공동 저작물의 권리와 표시 명칭
