# 제주너머 10분 발표 동선

## 0:00–1:20 문제 정의

제주는 귤·바다·카페 같은 단편 이미지로 소비되면서 마을별 문화와 제주어가 사라지고 있습니다. 제주너머는 관광지를 나열하지 않고 각 마을의 생활문화와 언어를 직접 말하게 만드는 게임입니다.

## 1:20–2:10 해결 방식

제주를 7읍·5면·`제주 열아홉 동네`·`서귀포 열두 동네`의 14개 탐험 권역으로 구성합니다. 한 권역을 완주할 때마다 설문대 할망의 기억 조각 1개를 얻고, 14개를 모두 모아야 기억이 완성됩니다. 데모는 구좌읍 1개와 세 문화 지점을 구현했습니다.

## 2:10–7:40 라이브 플레이

1. `기억의 길 열기` → 바람새 도입 대화 3회
2. 구좌읍 진입 → 송당리 본향당 선택
3. 바람새와 고인택 어르신의 대화가 화자에 따라 전환되는 장면 시연
4. `안녕하우꽈?`로 인사하고 설문대할망의 기억을 찾으러 왔다고 제주어로 전달
5. 하얀 지전 → 오색 물색 순서로 신목에 거는 미니게임 진행
6. `지전물색 정성껏 걸었수다` 문장을 직접 입력해 숲의 기억 각성
7. 송당 사람들이 함께 마을의 안녕과 생업을 빌며 이어온 문화가 기억으로 되살아나는 장면 확인
8. `함께 지켜온 숲의 약속`과 `구좌읍 기억의 흔적 1/3` 보상 확인
9. 하도리 토끼섬으로 떠나는 감사 인사 후 구좌 지도 복귀

현재 송당 시나리오의 네 입력은 정답 표현이 제시된 회화 연습이므로 단계별 필수 표현으로 즉시 확인합니다. 기존 자유형 문화 질문용 Gemini 판정 API는 유지되어 있지만, 질문과 판정 기준이 다른 송당 회화 단계에는 연결하지 않습니다.

송당 회화도 실제 Gemini로 판정하려면 인사·방문 목적·지전물색·감사 인사별 루브릭과 근거를 추가한 뒤 다음 구조로 연결합니다.

- 문화 지식 판정과 제주어 판정은 서로 영향을 주지 않도록 병렬 실행
- 신뢰성 에이전트가 허용된 근거 ID와 상충 여부를 재검증
- 마지막 통과 여부는 Python 결정론적 게이트가 확정

## 7:40–9:10 기술·신뢰성

- Google ADK `ParallelAgent + SequentialAgent`
- 기존 자유형 판정 API에서 Vertex AI Gemini 실제 호출 3회/판정
- 프롬프트 공격 사전 차단, 구조화 Pydantic 계약, 근거·힌트 화이트리스트
- 단위 테스트 66개와 UI API 계약 테스트 통과
- 실제 GCP Agent Runtime 배포 및 기존 Gemini Enterprise 앱 등록 완료

## 9:10–10:00 임팩트·확장

마을 주민·문화기관이 검수한 루브릭과 제주어 표현을 추가하면 14개 탐험 권역으로 확장할 수 있습니다. 이용자는 지식을 보기만 하는 대신 제주어로 직접 설명하며 지역의 언어와 생활문화를 능동적으로 기억하게 됩니다.

## 발표 전 체크

- `gcloud auth application-default login` 완료
- `/api/health`가 `ok`인지 확인
- `/api/health`의 `execution_backend=agent_runtime` 확인
- Gemini 판정 시연을 함께 할 경우 기존 자유형 판정 API를 미리 호출해 인증 상태 확인
- 브라우저 확대 100%, 데스크톱 1280×720 이상
- 네트워크 장애 시 가짜 성공 처리는 사용하지 않고 오류를 명시적으로 표시
