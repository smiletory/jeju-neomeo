# 제주너머 10분 발표 동선

## 0:00–1:20 문제 정의

제주는 귤·바다·카페 같은 반복된 이미지로 소비되면서 마을마다 다른 생활문화와 기억이 관광 경험에서 가려지고 있습니다. 제주너머는 유명 관광지를 나열하지 않고 마을 고유의 문화 지점을 탐험하며 제주의 지역 정체성을 발견하게 하는 게임입니다.

제주어는 별도의 암기형 학습 과정이 아니라, 지역 NPC와 실제로 대화하는 감각을 만드는 몰입 장치로 사용합니다.

## 1:20–2:10 해결 방식

제주를 7읍·5면·`제주 열아홉 동네`·`서귀포 열두 동네`의 14개 탐험 권역으로 구성합니다. 한 권역을 완주할 때마다 설문대 할망의 기억 조각 1개를 얻고, 14개를 모두 모으면 제주의 이야기가 완성됩니다.

데모는 구좌읍의 세 문화 지점을 구현했습니다.

- 송당리 본향당: 신목과 마을 공동체의 기억
- 하도리 토끼섬: 문주란 자생지와 자연유산 보호
- 동김녕리 해안: 잠수굿·멜후림소리와 공동체 노동

## 2:10–7:30 라이브 플레이

1. 제주 전체 지도에서 14개 탐험 권역과 구좌읍 해금 상태를 보여줍니다.
2. 구좌읍에 들어가 세 지점의 실제 상대 위치와 순차 해금 구조를 설명합니다.
3. 한 지점의 NPC 대화와 상세정보를 통해 문화가 시나리오 안에서 전달되는 장면을 보여줍니다.
4. 미니게임으로 관찰한 내용을 직접 행동으로 연결합니다.
5. 제주어 상황 입력 화면에서 의미가 맞고 표현도 적합한 답변을 제출합니다.
6. 문장 의미 판정 → 제주어 표현 판정이 순서대로 완료되는 UI를 보여줍니다.
7. 가능하면 표준어 답변 또는 의미가 반대인 제주어 답변도 한 번 입력해 단계별 피드백 차이를 보여줍니다.
8. 기억의 흔적을 획득하고 다음 지점이 해금되는 장면으로 게임 루프를 마무리합니다.

발표 시간이 부족하면 `미니게임 건너뛰기`, `제주어 입력 건너뛰기`, `지점 전체 건너뛰기`를 사용하되, Gemini 판정 시연 1회는 직접 진행합니다.

## 7:30–9:10 기술과 신뢰성

- 게임 서버와 Agent Runtime을 독립 배포해 브라우저에 인증정보를 노출하지 않았습니다.
- Google ADK `SequentialAgent` 안에서 Meaning Judge, Dialect Judge, Reliability Verifier가 순차 실행됩니다.
- 제주어 키워드가 있어도 문장 의미가 틀리면 첫 단계에서 통과하지 않습니다.
- 의미가 맞을 때만 제주어 표현과 사용 맥락을 검사합니다.
- 모델 결과는 Pydantic 구조, 승인 근거·힌트 목록과 Python 결정론적 게이트를 통과해야 합니다.
- 단위 테스트 74개와 UI API 계약 테스트가 통과합니다.
- 하도리·동김녕리 릴리스 평가 6건은 모두 유효했고 평균 품질은 5.0/5.0입니다.

## 9:10–10:00 임팩트와 확장

마을 주민과 문화기관이 검수한 시나리오·루브릭·제주어 용례를 추가하면 같은 게임 구조를 다른 13개 탐험 권역으로 확장할 수 있습니다. 이용자는 지역 문화를 설명문으로만 읽는 것이 아니라 NPC와 대화하고 행동하며 마을의 이야기를 경험합니다.

## 발표 전 체크

- 로컬 시연이면 `gcloud auth application-default login` 완료
- `/api/health` 응답 확인
- 발표용 답안 버튼과 세 종류의 건너뛰기 버튼 확인
- 브라우저 확대 100%, 데스크톱 1280×720 이상
- 네트워크 장애 시 가짜 성공 대신 오류가 표시되는지 확인
- 라이브 배포가 종료된 현재는 로컬 서버에서 시연
