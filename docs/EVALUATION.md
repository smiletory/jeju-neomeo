# 제주너머 최종 평가 보고서

## 평가 범위

최종 릴리스 평가는 실제 게임에서 Gemini 판정을 사용하는 하도리 토끼섬과 동김녕리 해안의 상황형 제주어 입력을 대상으로 수행했습니다.

각 지점마다 다음 세 유형을 검증했습니다.

1. 의미와 제주어 표현이 모두 적합한 답변
2. 의미는 적합하지만 표준어만 사용한 답변
3. 제주어처럼 보이는 표현은 포함하지만 상황 의미가 반대인 답변

## 평가 사례

| 지점 | 사례 | 기대 결과 |
|---|---|---|
| 하도리 토끼섬 | 문주란을 꺾지 말고 지켜달라는 제주어 부탁 | 통과 |
| 하도리 토끼섬 | 같은 의미를 표준어로만 전달 | 제주어 보완 |
| 하도리 토끼섬 | 제주어 종결을 쓰면서 문주란 훼손을 허용 | 의미 보완 |
| 동김녕리 해안 | 함께 모여 멜 그물을 당기자는 제주어 요청 | 통과 |
| 동김녕리 해안 | 같은 의미를 표준어로만 전달 | 제주어 보완 |
| 동김녕리 해안 | 제주어 단어를 쓰면서 함께 당기지 말라고 전달 | 의미 보완 |

## 신뢰성 검증 기준

평가 점수만으로 퀘스트를 통과시키지 않습니다. 실제 게임 API에서는 다음 조건을 추가로 검사합니다.

- 문장 의미가 현재 대화 상황과 일치하는가
- 금지된 반대 의미가 포함되지 않았는가
- 필수 제주어 표현이 올바른 뜻과 맥락으로 쓰였는가
- 에이전트가 승인된 근거와 힌트 ID만 반환했는가
- Meaning Judge와 Dialect Judge, Reliability Verifier 결과가 상충하지 않는가
- Pydantic 구조 검증과 Python 결정론적 게이트를 통과했는가

따라서 제주어 키워드만 나열하거나 제주어처럼 보이는 종결 표현을 붙이는 방식으로는 통과할 수 없습니다.

## 자동 테스트

```powershell
uv run pytest tests/unit -q
node tests/ui_agent_api.mjs
```

현재 단위 테스트 74개와 UI API 계약 테스트가 통과합니다. 자동 테스트는 API 계약, 근거 범위, 입력 공격 차단, 에이전트 결과 파싱, 최종 게이트와 Runtime 클라이언트를 포함합니다.

실제 Gemini 품질 평가는 네트워크·권한·비용이 필요하므로 수동 릴리스 평가로 분리하고, GitHub Actions에서는 결정론적 단위 테스트와 UI 계약 검사를 실행합니다.
